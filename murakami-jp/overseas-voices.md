# 海外の声の洗い出し(2026-10-02)

目的: プロローグで約束した「日本だけでなく、多様な国々の読者・批評家・研究者の声が集まってできた本」を、本文で実現するための棚卸し。
検証の凡例: **済** = 原典または貼付された本文で確認済み / **引き** = 英語版3巻の出典一覧にある(原典は未照合) / **手がかり** = 検索結果や記憶によるもの。引用に使う前に、必ず原典で確認する。

## 1. 結論

- 現在の本文には、海外の声がほとんどない。ある海外要素は、翻訳者の名前(バーンバウム、ルービン、ゲイブリエル)、英語圏の受賞や書評の事実(ニューヨーク・タイムズの十大ブック、ワールド・ファンタジー賞、The Millions)、中国側の反応(南京紀念館、人民網)、ブックメーカーの倍率、シンポジウムの地理にとどまる。
- 英語版3巻の出典一覧にも、英語圏の村上論の書籍・論文は一冊も入っていない。つまり、著者紹介にある「英語圏の村上論を網羅的に読んできた」は、いまの原稿の中身が裏づけていない。**対応は二択**: (a) 実際に英語圏・中国語圏の文献を読んで本文に入れる、(b) 著者紹介の表現を弱める。推奨は(a)で、少なくとも各幕に数点ずつ入れてから、紹介文の強さを決めること。
- この環境からは、新潮社、リアルサウンド、Paris Review、早稲田国際文学館、日文研のリポジトリなどが開けない(アクセス遮断)。本文の確認には、あなたが開いて貼る、または手元の本のページを撮影する方法が、いちばん確実。

## 4. 進め方の提案

1. まず、**第1章と第7章**に海外の声を入れる(この本の問いに最も近く、読者の関心も強い)。必要な一次資料: ルービン『Music of Words』の該当ページ(手元にあれば撮影)、グーセンまたはバーンバウムの序文。
2. 次に、**東アジアの受容**(第7章、第13章、第19章)。早稲田国際文学館のエッセイと、中国語圏の受容についての論文を、あなたが開いて貼る。
3. 第11章・第12章は、英語圏の書評を一本ずつ(NYT、ガーディアンなど)。貼ってもらうか、あなたが読んで要点を教える。
4. 第15章は、すでに海外の声が多いので、一次確認だけ。
5. 並行して、著者紹介の表現は、(a)の見通しが立つまで、現状のままにするか、弱めるかを決める。

声を入れる形は、各章の終わりに「海外から見ると」の小節を1つ(300〜500字)置く案と、本文の流れに織りこむ案がある。読みやすさでは前者、約束の実現では後者が強い。章ごとに決める。
