# ノーベル賞 結果別の差し替え手順(日本語版)

発表: 2026年10月8日(木)20:00以降(日本時間)。

1. 結果を確認する(ノーベル賞公式サイト)。受賞者、授賞理由(原文と日本語訳)、発表時刻を、公式の発表で確認する。
2. `win.md`(村上春樹が受賞)か `no-win.md`(ほかの人が受賞)の `[[FILL: …]]` を、すべて埋める。見たもの、確認できたものだけを書く。授賞理由に書かれていないことは書かない。
3. `python3 apply_nobel.py win` または `no` を実行する。FILLが残っていると止まる。
4. 本文の結果に左右される箇所を、手で確認する(下表)。
5. 人間らしさの推敲(第18章の新しい節と終章)。「〜ではなく」は1章に2回まで。
6. 説明文・キーワードを、結果に合わせて書く。EPUBは、依頼があるまで作らない。

| 箇所 | 受賞 | 受賞せず |
|---|---|---|
| 第三幕の冒頭(「結果の出る二〇二六年十月まで」) | 「結果の出た二〇二六年十月まで」に変える | 同左 |
| 第18章 後半 | win.md | no-win.md |
| 終章の結び | win.md | no-win.md |
| 年表の最終行 | win.md(自動) | no-win.md(自動) |
| プロローグ | 変更なし | 変更なし |
| 用語集の「五十年ルール」 | 変更なし | 変更なし |
| 著者紹介 | 変更なし | 変更なし |
| 副題(『…世界で読まれた「声」の全記録』) | 受賞を謳うかは別途判断 | 変更なし |
| 日本語版の商品説明の冒頭 | 受賞を先頭に出せる | 結果に触れず、声の話から入る |
| 広告 | 受賞直後は需要が高い。単価と費用対効果を再計算 | 同左。需要は例年並み |
