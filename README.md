## noteへの投稿手順
note.comのエディタはMarkdown記法（`#`や`-`など）を解釈しないため、`.md`ファイルをそのままコピペしても見出しやリストは反映されない。そこでリッチテキスト（HTML）としてコピーすることで見出し・リストを引き継がせる。

**方法1: スタンドアロンHTML（ブラウザで別途開く）**
1. `python3 scripts/build_note_html.py` を実行し、`articles/note_html/*.html` を最新化する
2. 対象のHTMLファイルをブラウザで開く
3. 赤枠のタイトル部分はnote投稿画面の「タイトル」欄に別途コピペする
4. 「ここから下」と書かれた本文部分を選択してコピーし、note本文欄に貼り付ける（見出し・リストが自動で反映される）

`.md`を編集したら、都度スクリプトを再実行してHTMLを更新すること。

**方法2: Artifactでこの画面上に表示（011〜で採用）**
タイトル・本文それぞれに「コピー」ボタンが付いたページをArtifactとしてpublishし、ボタン一つでリッチテキストをクリップボードにコピーできるようにする形。デザイン・実装方針は`personas/note_account_concept.md`の「Artifactでのオンスクリーン表示について」を参照。
