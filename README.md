# kindle

日本語教師歴15年・関西圏のベテラン教員（「全国【登録日本語教員試験】研究グループ」メンバーという設定）のnoteアカウント運営と、Kindle『登録日本語教員試験　決定版問題集　基礎から応用試験対策＋本番予想模擬試験　厳選　全500問　詳細な解説付き』の販促を目的としたコンテンツ置き場。単なる受験生向け便利情報サイトではなく、業界の待遇改善への問題提起と、この仕事の喜び・可能性の発信を両輪とする。

## 構成
- `personas/note_account_concept.md` — noteアカウントの設計（ペルソナ・理念・コンテンツ4本柱・文体方針）
- `personas/note_profile.md` — noteプロフィール欄・固定記事用の自己紹介ドラフト
- `.claude/skills/humanize-writing/SKILL.md` — 一人称エッセイをAI臭くなく書くためのチェックリスト。記事執筆時に参照する
- `articles/note/` — note投稿記事のドラフト（連番）
  - 000 — 自己紹介・アカウントの方向性（固定記事想定）
  - 001, 002 — 制度・試験情報
  - 003, 004 — 実務エッセイ（試験と現場のズレ／教える喜び）
  - 005 — 業界の待遇・構造への問題提起
  - 006 — 試験当日までのカウントダウンエッセイ（11月8日試験、執筆時点で残り53日）
