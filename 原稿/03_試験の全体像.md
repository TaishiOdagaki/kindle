# 第3章　試験の全体像

この章の数字は、令和7年度(2025年度)の試験案内と実施結果にもとづいている。令和8年度以降の出願の前には、必ず最新の案内を確認してほしい。

## 試験は2つ、形式はどちらも選択式

| | 基礎試験 | 応用試験 |
|---|---|---|
| 内容 | 日本語教育に必要な基礎的な知識・技能 | 基礎知識の応用 |
| 構成 | 一つの試験 | 読解と聴解 |
| 時間 | 120分 | 読解100分、聴解50分程度 |
| 問題数 | 100問 | 読解60問、聴解50問 |
| 配点 | 1問1点(100点) | 1問1点(計110点) |

出典は令和7年度の試験案内。応用試験の聴解は音声を聞いて答える形式で、読解は資料を読んで答える。【要確認: 聴解の「50分程度」の内訳(説明・解答時間を含むか)】

## 合格基準

令和7年度の試験案内によれば、基礎試験は、必須の教育内容の5つの区分それぞれで6割程度、かつ、全体で8割程度の得点が合格の基準とされている。応用試験は、全体で6割程度の得点だ。【要確認: 「程度」の扱い、年度ごとの変更の有無】

基礎試験には2つの条件が重なっている。5区分のどれかを落とすと、総合点が高くても合格できない。全体で8割とるには、得意な区分だけを伸ばしても足りない。苦手な区分を作らないことが、基礎試験の対策の核心になる。

応用試験は総合点だけで判断される。聴解で点が伸びなくても、読解で挽回できる計算になる。

## 結果の数字をどう読むか

令和6年度(2024年11月17日実施)は、受験者17,655人、合格者11,051人で、合格率は62.6%と発表された。令和7年度(2025年11月2日実施)は、受験者17,597人、合格者11,876人、合格率は67.5%だった。

ただし、この数字は読み方に注意がいる。合格者には、試験の一部または全部が免除された人が多く含まれている。令和6年度の合格者のうち、全試験免除の人が5,958人。つまり合格者の半分以上は、試験問題を解かずに合格している。これから試験を受ける人にとっての実際の難しさは、この全体の合格率とは別に考えたほうがいい。

「合格率が6割だから、ほどほどの準備でいい」とは言い切れない。免除を受けない受験者がどれだけ合格したかは、公式の実施結果の表から、ルート別の数字を見るしかない。

## 出願から合格発表まで

実施は年1回で、令和6年度は11月17日、令和7年度は11月2日だった。出願はオンラインで、夏に締め切られる。令和7年度は7月14日から8月22日まで。合格発表は、令和6年度が試験の約1か月後、12月20日だった。

試験地は、令和6年度が8地域。令和7年度の会場数は、資料により表記が分かれるので、ここでは断定しない。

令和8年度は、試験日が11月8日(日)、出願期間が7月13日から8月21日までで、結果の通知は12月18日の予定と案内されている。受験料は、通常(基礎+応用)で18,900円。受験料は、基礎試験の免除を受ける場合が17,300円、基礎・応用の両方の免除を受ける場合が5,900円。令和8年6月公開の文部科学省「登録申請の手引き」にも同じ日程と金額が載っている。試験地は、北海道、東北、関東、中部、近畿、中四国、九州、沖縄の8地区の予定。形式・時間・問題数・配点は令和7年度と同じ(基礎120分100問、応用は読解100分60問・聴解50分程度50問)。【要確認: 受験票の発行日と、地区内の具体的な会場。出典は文部科学省の試験ページの検索要約で、原文は未確認】

## 免除と出願

基礎試験が免除されるのは、登録日本語教員養成機関の養成課程を修了した人、過去の日本語教員試験で基礎試験に合格し基礎試験合格証明書を持つ人、経過措置の対象者だ。免除を受けるには、出願のときに、修了証明書などの書類を一緒に出す。

経過措置のE-1・E-2では、基礎・応用の両方が免除される。それでも、手数料5,900円を払って出願し、経過措置の対象であることの確認を受け、合格証書を手に入れなければならない。登録の申請に、その合格証書が要るからだ。現職者の経過措置の対象になる最後の試験は、令和10年度の試験とされている。

出願時に養成課程の修了が間に合っていない場合は、翌年の4月までに修了証明書を出す。それまでは仮合格の扱いで、期限に出せなければ合格は取り消される。

## 当日までに知っておくと楽になること

- 免除の書類が要る人は、出願期間(令和8年度は7月13日から8月21日)のなるべく早い時期に準備しておく。在職証明書などは、勤務先に頼んで発行してもらう書類だ。
- 基礎試験は120分で100問、1問あたり約1.2分。見直しの時間も含めると、1問に長く悩む余裕はない。
- 応用試験の読解は100分で60問。1問あたり約1.7分。ケースの文章を読む時間が含まれるため、設問を先に見てから資料を読むなどの工夫が効く。第6章で触れる。
