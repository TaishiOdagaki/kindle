# 第5章　基礎試験の問題を解いてみる

問題を見る前に、一つだけ言っておきたい。この章の問題は、実際の試験問題ではない。公表されている出題範囲をもとに、私たちが作ったものだ。形式と難しさの「手触り」をつかむための見本として読んでほしい。

四択問題には、どれも作られ方に癖がある。正解を作るのは簡単で、むずかしいのは「もっともらしい誤答」のほうだ。誤答がどうやって作られているかが見えてくると、知識が少し足りなくても、迷う選択肢を2つまでは絞れる。

ここでは4問を解く。出題範囲の区分でいうと、社会・文化・地域、言語と教育、言語と心理、言語の4つから1問ずつ。

## 問1　在留資格を比べる(社会・文化・地域)

**在留資格「特定技能1号」および「特定技能2号」の比較に関する記述として、最も適切なものを一つ選びなさい。**

1. 「特定技能1号」は通算で最長5年までの在留制限があり、「特定技能2号」は更新に上限がなく長期滞在や永住申請の道が開かれている。
2. 「特定技能1号」では配偶者や子の帯同が自由に認められるが、「特定技能2号」では原則として家族の帯同が認められていない。
3. 「特定技能1号」の取得には技能実習3号の修了または試験の合格が必要であるが、「特定技能2号」は実務経験のみで試験なしで取得できる。
4. 「特定技能1号」の受け入れ機関には生活支援等の手厚い義務が課されるが、「特定技能2号」では外国人本人の独立性が高いため、就労先企業の支援責任は一切発生しない。

**ここで考える。** 1号と2号、どちらがどちらだったか。

**正解は1。** 1号は通算5年が上限で、2号は更新に上限がない。2号は、要件を満たせば永住許可の申請にもつながる。

2は、きれいに逆になっている。家族の帯同が原則認められないのは1号のほうだ。問題文の中で「1号」と「2号」の性質を入れ替えるのは、この種の問題でいちばん多い誤答の作り方で、番号を取り違える注意力をみられている。

3は、2号を「試験なし」と言い切ったところが誤り。2号には、1号より高い水準の「熟練した技能」を確認する試験などの要件がある。「実務経験のみ」「試験なし」と言い切る書き方は、疑ってかかってよい。

4は、「一切発生しない」。企業の責任は、支援計画の義務がなくなっても消えない。労働条件や法令遵守の責任は、2号でも残る。

「一切」「すべて」「必ず」「のみ」のような断定語が入った選択肢は、正解になりにくい。ただし、これはあくまで傾向で、断定語が入っているだけで切ってよいわけではない。次の問2でそれを見る。

## 問2　試験問題に、著作物を使えるか(言語と教育)

**著作権法第36条(試験問題としての複製等)に関する記述として、最も適切なものはどれか。**

1. 定期試験や入学試験の問題として公表された著作物を必要な限度で利用する場合、非営利の試験であれば、著作者への補償金の支払いや許諾なしに複製して試験問題として配布できる。
2. 試験問題として利用した著作物は、試験終了後であれば、著作権者の許諾を得ることなく無条件で市販の過去問題集として出版・販売することができる。
3. 試験問題として著作物を利用する場合であっても、原作の文章をひらがなに直したり、難解な語彙を初級語彙に言い換えたりする「要約・改変」は法律上いかなる場合も絶対に認められない。
4. 試験問題として著作物を利用できるのは、営利を目的としない試験(学校の定期テストなど)に限られ、営利目的で行われる検定試験では一切の利用が禁止されている。

**ここで考える。** 正解の選択肢1に、断定語はない。逆に、誤答のほうに「無条件」「いかなる場合も絶対に」「一切」が3つ並んでいる。

**正解は1。** 第36条は、試験や検定の問題として、公表された著作物を必要な限度で複製できると定めている。非営利の試験なら、補償金も要らない。

条文には但書がある。営利を目的とする場合は、通常の使用料に相当する額の補償金を、著作権者に支払わなければならない。だから4は誤りだ。営利の検定試験でも、利用そのものは禁じられていない。「補償金が要る」という条件がつくだけで、「一切禁止」とは違う。

2も誤り。試験の実施のための複製と、あとから過去問題集として出版・販売することは別の行為で、後者には許諾が要る。

3は、「いかなる場合も絶対に」が危ない。受験者の水準に合わせた必要な範囲の改変が認められる場合がある。

この問題は、条文の但書まで読んでいたかを問うている。法令の問題で、条文の本文だけ覚えていると、4を選んでしまう。

## 問3　「化石化」の例を選ぶ(言語と心理)

**学習者の発音や文法に見られる「化石化」の具体例とその要因に関する記述として、最も適切なものを一つ選びなさい。**

1. 中国語を母語とする学習者が、日本語の「つ」の発音を「す」と発音してしまったが、発音指導を受けた直後に正しく発音できるようになった。
2. 学習者が「高い」の過去形を「高かったです」と正しく発話できた後、翌日「\*高かったでした」と誤用するようになった。
3. 初級の学習者が「行きます」の否定形として「行きない」と誤ったが、教師から「行かない」とフィードバックを受け、直後の会話で「行かない」と正しく言い直し、その後の会話でも同じ誤りを繰り返さなかった。
4. 日本滞在歴15年の上級学習者が、日常のコミュニケーションで全く支障がないため、「\*先週、友達に会いました(正しくは『友達と』)」などの特定の助詞の誤りを意識せず何年も使い続けている。

**ここで考える。** 3つの選択肢には、そろって「直った」という要素が入っている。

**正解は4。** 化石化は、誤りが定着して、その後の学習が進んでも直らなくなる現象のこと。この選択肢には、長い滞在歴、日常生活に支障がないこと、誤りに気づいていないこと、の3つがそろっている。通じてしまうために、直す必要を感じない。それが定着を後押しする。

1と3は、指導を受けて直った例だ。化石化とは反対の事例になっている。

2は少しややこしい。一度できたものが、あとで一時的に崩れる。これは言語習得の過程でよく見られるU字型の発達と呼ばれる現象で、誤りが固まったわけではない。

「化石化」という語の意味を知らなくても、「直った」という要素を探せば、1と3は落とせる。覚えた用語の定義を、事例に当てはめる問題の典型だ。

## 問4　くれる・もらう・あげる(言語)

**授受表現(やりもらい:「やる・あげる・さしあげる」「もらう・いただく」「くれる・くださる」)の視点と文法構造に関する記述として、最も適切なものはどれか。**

1. 心理的距離やウチ・ソトの関係において、自分の家族(身内)が第三者から物品を受け取った場合、「〜が弟にあげた」と表現するのが文法的に正しい。
2. 「もらう・いただく」は、常に受け手(自分または身内)が主語になり、与え手は格助詞「ヲ」で指示される。
3. 「あげる」と「もらう」は視点が完全に同一であり、文中の主語と目的語の位置(格関係)を入れ替えても文のニュアンスや視線方向は変化しない。
4. 「くれる・くださる」は、他者が話し手(または話し手と同集団の身内)に向かって利益や物品を与える場合に使用され、視点は受け手である話し手の側に置かれる。

**ここで考える。** 授受表現の問題では、「誰の立場から見ているか」を問われる。

**正解は4。** 「くれる」は、物が話し手の側に向かって来る。話し手(または身内)が受け手で、視点もそこにある。

1は、身内が第三者から物をもらった場面なのに「あげた」を使っている。「〜が弟にくれた」と言う。「あげる」を使うと、弟が与え手になってしまう。

2は、前半の「受け手が主語になる」は合っているのに、与え手を示す助詞が違う。与え手は「ニ」か「カラ」で示す。「ヲ」は物品を示す助詞だ。前半が正しくて後半だけ違う、という作りの誤答は、読み飛ばすと拾ってしまう。

3は、「完全に同一」と言い切っている。「あげる」は与え手の側、「もらう」は受け手の側から描く。

この4問に共通しているのは、誤答が「ほとんど正しい文」でできているということだ。正解と見比べて、どこか一箇所だけを入れ替えるか、言い切りに変えてある。見分ける手がかりは、知識そのものと、言葉の端々にある。
