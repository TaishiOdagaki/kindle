## 出願前
- [ ] 自分のルートを決めた(第2章)
- [ ] 免除の対象か確認した。対象なら、必要書類(修了証明書、学位の証明書、在職証明書など)を取り寄せた
- [ ] 現職者向け講習が必要なルート(D-1・D-2・E-1・E-2)なら、出願の時点で修了証が手元にある。令和10年度の試験が現職者の経過措置を受けられる最後
- [ ] 最新の試験案内を読んだ(日程・試験地・受験料・出願方法)
- [ ] 受験料を準備した(令和8年度: 基礎+応用18,900円/基礎免除17,300円/双方免除5,900円)

## 出願〜試験前日
- [ ] オンラインで出願した
- [ ] 受験票を確認した
- [ ] 試験会場と経路を確認した
- [ ] 持ち物を確認した(受験票、筆記用具、本人確認書類、時計。細目は案内で確認)

## 合格後
- [ ] 実践研修の申込み(免除されないルートの人。時間と費用は機関ごとに異なる)
- [ ] 住民票の写し(本籍地記載、マイナンバーなし)か戸籍謄本・抄本を、登録申請日の6か月前以降のもので用意した
- [ ] ポータルサイトで申請情報を入力し、合格証書(PDF)などをアップロードした
- [ ] 登録手数料4,400円を支払った(収入印紙または電子納付)
- [ ] 申請・届出書などを簡易書留で送った(レターパックは不可)
- [ ] 登録証をポータルサイトからダウンロードした
