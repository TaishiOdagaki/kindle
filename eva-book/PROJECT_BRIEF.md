## 1. 企画の核

**一言でいうと**
日本語圏で積み上がった考察・批評・制作背景の知見を、英語圏の読者のために整理し、
「あらすじ → 設定 → 解釈 → 批評 → 作者論」まで一冊で通せる決定版にする。

**ターゲット読者(優先順)**
1. 旧作は観たが「結局どういう話か」を整理できていない英語圏ファン(最大のボリューム)
2. 新作(完全新作)をきっかけに初めて入る新規層
3. アニメ批評・日本文化に関心のある一般読者・学生

**価値提案(競合との差)**
- 日本語一次情報(雑誌インタビュー、公式資料、制作者発言)に基づく**証拠の階層表示**
- 英語圏に届きにくい日本側の議論史(90年代の受容、旧劇場版への反応、新劇場版での再解釈)
- ネタバレ構造が明確で、初見でも再視聴者でも使える設計

> 競合調査は未実施(要確認)。Amazon.com / .co.uk の既存書籍を実際に洗い出し、
> 「何が足りないか」を1ページにまとめてから目次を確定する。

## 2. 本書の「背骨」(論旨)

決定版を名乗る本には、情報の網羅だけでなく**一貫した主張**が要る。候補:

- **A案: 「対話の拒絶と渇望」** — ATフィールド/ヤマアラシのジレンマを軸に、
  TV版 → 旧劇場版 → 新劇場版を「他者との接触という同じ問いへの3回の回答」として読む。
- **B案: 「作者と観客の26年」** — 庵野秀明の制作環境の変化と、観客との関係の変化を軸にした作者論的読解。
- **C案: A+B 統合** — 主題(A)を、作者の変遷(B)で裏づける。**推奨**。

## 4. 執筆原則

**証拠の3階層(全章で明示)**
| ラベル | 意味 |
|---|---|
| **Shown** | 作中で画面・台詞により確定している |
| **Stated** | 制作者の公式発言・公式資料による |
| **Interpreted** | 筆者または批評上の解釈 |

**その他**
- 「決定版」「完璧」を保証する根拠は、網羅性ではなく**検証の透明性**に置く。
- 異説は併記し、どれが誰の説かを明記する。断定しすぎない。
- 日本語資料は引用を最小限にし、自前の要約・翻訳で扱う。
- 事実(公開日・話数・スタッフ名など)は必ず一次情報で照合してから確定する。

## 5. 権利・出版リスクの設計方針(2026-10-05 方針更新)

**方針**: 「Unofficial」の表記なし、台詞引用を豊富に、弁護士確認なし、を目標にする。
ただしこの3点は**互いに法的リスクを押し上げる方向**にあるため、次の設計でリスクを下げる。
「弁護士確認が不要」と保証することは私にはできない。リスクを下げる設計と、残るリスクの引き受けは出版側の判断。

| 項目 | 設計 |
|---|---|
| 台詞引用 | 引用は**批評の対象を示す最小限**(短い一節)にし、**各引用の直後に自前の分析**を置く。引用だけの羅列・場面の台詞を通して再現する構成は避ける。「豊富」は**量ではなく、分析との密度**で実現する |
| 非公式の表示 | タイトル・表紙に「Unofficial」は入れない。代わりに**奥付に「本書は制作者・権利者と提携・承認関係にない」旨**を入れる(公式と誤認させない最低限の表示。タイトル自体は説明的な "A Critical Guide" 等を使う) |
| 画像 | 作中画像・ロゴ・設定資料は一切使わない。表紙・図版は独自制作 |
| 商標 | 作品名・キャラクター名は**書名内で作品を指す目的に限る**。ロゴ風の書体や配色の模倣は避ける |
| KDP | AI生成コンテンツの申告が必要。AIが担う範囲を事前に決める |

**残るリスク**: 引用量が増えるほど、また公式と誤認され得る体裁になるほど、権利者からの削除申立てやアカウント上の問題が起きやすい。
確認コストを減らしたいなら、(1)引用を短くする、(2)奥付の表示を入れる、の2点が効果が大きい。
