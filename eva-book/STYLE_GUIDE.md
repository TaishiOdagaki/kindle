# 文体・引用ルール(v0.1)

## 1. 証拠の3階層(全章で使う)
| ラベル | 意味 | 例 |
|---|---|---|
| **Shown** | 作中の映像・台詞で確定 | 「第◯話で◯◯と明言される」 |
| **Stated** | 制作者の発言・公式資料で確定(**出典必須**) | 「庵野は◯年の◯◯でこう述べている」 |
| **Interpreted** | 筆者・批評家の解釈 | 「本書はこれを◯◯と読む」 |
- 異説は併記し、**誰の説か**を書く。断定しすぎない。
- Stated は**原則2つの独立した出典**、無理なら出典1つ+「単独の出典」と明記。

## 2. 引用ルール
**方針**(ユーザー決定: 台詞引用は豊富に。ただし法的リスクが引用量とともに上がるため、運用ルールで管理)

| 項目 | 既定値(変更可) |
|---|---|
| 1回の引用の長さ | **1文または約25語まで** |
| 引用の直後 | **必ず自前の分析を置く**(引用だけで終わらせない) |
| 場面の台詞を連続して再現 | **しない**(要約し、鍵となる一節だけ引く) |
| 1章あたりの引用数 | 目安: 各話ガイドの章で最大20、他の章で最大12 |
| 引用元の翻訳 | **自前の翻訳**を基本。公式字幕・公式翻訳の文言を転載しない |
| 日本語原文 | 鍵となる語句のみ(原語の意味を論じるとき) |

この表の数値は**運用上の目安**であり、法的な安全を保証するものではない(PROJECT_BRIEF §5)。
引用量を増やす場合は、「分析の密度」を同時に上げる。

## 3. 表記
- 人名: 作中の英語表記(**Shinji Ikari**)。初出で日本語表記を併記。以降は名のみ可。
- 作品名: 初出で正式名称、以降は略称(*Eva*, *EoE*, *Rebuild*)。**略称は How to Read で定義**。
- 日本語のローマ字: ヘボン式、長音は省略(Tokyo)、作中の公式表記を優先。
- 作品タイトル・用語は atlas の項目に合わせる。

## 4. ネタバレ方針
- Front matter の Primer(ネタバレなし)以外は**ネタバレあり**。
- 各章の冒頭に「この章が扱う範囲」を1行で示し、読者が読む順を選べるようにする。

## 5. 文体
- 平易な英語(大学1年〜一般読者)。**学術用語は初出で説明**。
- 1段落1論点。批評的な主張には**根拠(場面・発言)**を添える。
- 「決定版」を自称しない(根拠は網羅性ではなく、**検証の透明性**)。

## 6. 禁止
- 作中画像・設定資料・ロゴの転載
- atlas で `verified` でない事実を本文で断定すること
- 出典のない「制作者の意図」の断定

## 7. 日本語版の文体(日本語版が正本)
- **文体**: だ・である調(常体)。評論的な記述に合うため。変更する場合は全章で統一する。
- **用語**: 作中の公式表記を優先(使徒、ATフィールド、人類補完計画、ゼーレ、ネルフ等)。英語表記は初出で併記する(翻訳準備のため)。
- **人名**: 作中の表記(碇シンジ等)。「新劇場版」の人名の違い(例: 式波)は、該当する章で明記する。
- **証拠ラベル**: 日本語版では **描写 / 発言 / 解釈**(英語版で Shown / Stated / Interpreted)。
- **確認の印**: 作品・一次資料での確認が済んでいない箇所には `[[CHECK: 何を確認するか]]` を付ける。1つでも残るとリリースできない。
- **引用**: 台詞の引用は短く(1文程度まで)。引用の直後に分析を置く。正確な文言が未確認の場合は引用せず、`[[CHECK]]` を付けて要約にとどめる。
- **翻訳しやすさ**: 日本語特有の婉曲・省略(主語の省略等)は、英訳で意味が曖昧にならないよう、**主語と対象を明示**して書く。

## 8. 分冊に対応した書き方
- **章への参照は章IDで書く**: `{{c26}}`(単独)/ `{{c05..c09}}`(範囲)。ビルド時に、巻をまたぐ場合は「第3巻 第2章」、同じ巻なら「第2章」に解決される。**「第26章」のような数字の直書きはしない**。
- **共通ファイルの巻別記述**: 前付・巻末のように複数巻で共有するファイルでは、`<!--vol 1-->…<!--/vol-->` で巻ごとの記述を切り替える。
- **各巻の自立性**: 他巻の内容に依存する説明は、その巻の中で**最低限の要約**を添える。

## 9. 声(エッセイ調)——採用(2026-10-05。見本: `VOICE_SAMPLE.md`。第10・11章を書き直した)

**背景**: 第10・11章の初稿は、「描写/発言/解釈」の型を段落ごとに並べたため、百科事典のような文体になった。読み物としての声と、**本書の背骨(他者との接触)**が本文に出てこなかった。以下の方針に改める。

### 構成の分け方
| 部分 | 書き方 |
|---|---|
| **本文** | **エッセイとして読める文章**。見出しごとに小さな問いと主張を持つ。型(【描写】【発言】【解釈】)の見出しは**使わない** |
| **根拠(証拠の三階層)** | **脚注**に移す。「描写。第◯話」「発言。出典」「解釈。誰の読みか」の形。Kindleではポップアップで読める。**根拠の仕組みは変えない**(未確認の印も脚注に置く) |
| **資料(参照用)** | 表・用語一覧・話数一覧は、節の末尾の「資料」欄にまとめ、**本文の流れを切らない** |

### 文章の技法(過去の指針 `humanize-writing` から、**文章の技法の部分だけ**を採用)
- **文のリズムを崩す**: 短い文を続けたあと、長い文を挟む。1行だけの断定も置く。
- **具体的な場面・数字・小道具**を入れる(話数、場面、台詞の言い換え)。ただし**事実は作品で確認したもの**に限る。
- **接続詞(まず・次に・さらに・つまり)で骨組みを作らない**。文と文を、そのままぶつける。
- **数を揃えない**: 論点は3つに丸めない。2つでも、5つでもよい。
- **未解決を残す**: すべての問いに答えを出さない。「まだ言い切れない」を許す。
- **総括で終わらない**: 節を「このように〜が重要である」で閉じない。次の問い、短い断定、場面で終える。
- **抽象的な評価語(重要、大切、〜と言えるだろう)に頼らない**。
- **「〜とされる」「〜が示される」の連発を避ける**。誰が・何が、を主語にする。

### 採用しない部分(重要)
過去の指針には、「読者が『この人は本当に経験した人だ』と信じられるように」書く、という目的があった。本書は**体験談を装わない**。
- **架空の個人的体験(「子どもの頃に観た」「初めて観たとき泣いた」等)を、書き手に代わって作らない**。
- 一人称の「私」は、**読み・考えの主体**(「私は、そう読む」「私には言い切れない」)として使う。生活上の出来事としては使わない。
- 書き手本人の実際の記憶を入れたい場合は、`[[著者の記憶: ]]` の印を置き、**書き手が自分の言葉で埋める**。印が残るとリリースできない。

### 確認事項
- 誇張・断定を避けつつ、**立場を取る**(「〜と読む」と書く)。異説は、誰の説かを書いて併記する。
- 「エッセイ風」でも、**事実は未確認のまま断定しない**。確認の印の仕組みは、そのまま残す。

## 10. 著者名義と声(Jiro Naozane)

- **著者名義**: Jiro Naozane。出版社名義は Japanese Culture Press。メタデータ・奥付・表紙に反映済み。
- **声の方針**: データ・資料・説明が非常に多い本だが、**作品への愛と、面白がる書き方**を、少し意識して残す。ユーモア・驚き・「たまらなく面白い」といった熱量は、**作品や事実の面白さ**に向ける。
- **声の調整**: 著者の過去の文章(note、ブログ、書籍など)の**サンプルを2〜3点**もらい、語尾・比喩・間の取り方・冗談の質を合わせる。サンプルがない現在は、STYLE_GUIDE 第9節の方針で書き、**調整前の稿**として扱う。
- **好みの表明**(「好きだ」「たまらない」等)と**感想**は、**著者の実際の感じ方に差し替える**。本文中の該当箇所は、著者が確認する。
- **架空の経歴・体験談を作らない**(第9節)。著者の実際の記憶は `[[著者の記憶: ]]` で差し込む。
- **AI生成コンテンツの申告**: 本書の文章の多くはAIが下書きする。KDPの入力画面で、AI生成コンテンツの申告が必要になる(要・現行要件の確認)。名義の使用と、AI生成の申告は、別の話として扱う。
- **事実の扱い**: 面白がる書き方でも、事実は**確認済みのもの**だけを断定する。未確認は脚注の `[[CHECK]]` に残す。

## 11. 各話ガイドの方針(方針A、2026-10-05 決定)

- 各話は「あらすじ(3文以内)/見どころ(分析)/あとで効く(回収の予告)」の三つに分ける。
- 台詞は引用しない。場面を順に再現しない(権利面の配慮と、分析の密度を上げるため)。
- 題名・用語・設定名の言及は可。解釈は「私は〜と読む」と明示し、作品が説明していることと区別する。
