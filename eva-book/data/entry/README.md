# 視聴確認の記入表(話数カード・使徒)

全話の視聴にもとづく確認を、**表計算ソフト(Excel / Googleスプレッドシート等)で記入**し、取り込むと、データ(atlas)と話数カードに反映される。

| ファイル | 内容 |
|---|---|
| `episodes.csv` | 26話分。題名・放映日・出撃・中心人物・明かされる設定・版による差 |
| `angels.csv` | 使徒17体分(アダム・リリスを含む)。登場話数 |

## 1. 記入のルール
| 書き方 | 意味 |
|---|---|
| **空欄** | まだ記入していない |
| **`-`(ハイフン)** | 確認したが、**なし**(例: その話に出撃がない)。カードには「なし」と表示される |
| **`;` で区切る** | 複数の項目(例: `初号機(碇シンジ);零号機(綾波レイ)`)。全角の `;` も可 |
| **○**(`ok` 列) | その行を**作品を視聴して確認した**。確認者・確認日が必須 |

`(参考)` で始まる列は**読み取り専用**(取り込み時に無視される)。

## 2. `episodes.csv` の列
| 列 | 内容 | 書式・注意 |
|---|---|---|
| `episode` | 話数 | **変更しない** |
| `title_jp` | 題名 | 現在は**記憶による仮入力**。公式表記(句読点、「アイ/愛」等)に直す |
| `title_en` | 英題 | 任意。**配信・ソフトにより英題が異なる**ので、`note` に出所を書く |
| `air_date_jp` | 放映日 | `YYYY-MM-DD`(例: `1995-10-04`) |
| `viewed_edition` | 視聴した版 | 例: `TV放映版` / `ディレクターズカット` / `Netflix版` 等。**版による差があるため必須** |
| `sorties` | 出撃した機体 | 例: `初号機(碇シンジ)`。**短く**(1行26字以内、2行まで) |
| `focus` | 中心人物 | 人物名、または人物ID(例: `ch-shinji`)。複数は `;` 区切り |
| `reveals` | その話で新たに明かされる設定 | 短い語句で。複数は `;` 区切り |
| `version_note` | 版による差 | 差があれば短く。なければ `-` |
| `ok` | 確認済み | `○` |
| `checked_by` | 確認者 | 名前またはイニシャル |
| `checked_date` | 確認日 | `YYYY-MM-DD` |
| `note` | メモ | 自由記述(出所、迷った点など) |

**○にする条件**: `title_jp` `air_date_jp` `viewed_edition` `sorties` `focus` `reveals` `version_note` が、**すべて空欄でない**こと(なければ `-`)。満たさないと、取り込み時にエラーになる。

## 3. `angels.csv` の列
| 列 | 内容 | 書式・注意 |
|---|---|---|
| `number` / `name_jp` / `name_en` | 使徒の番号・名前 | 誤りがあれば直す |
| `episodes` | **登場する話数** | 数字を `;` 区切り(例: `2;3`)。戦わない使徒は `-` |
| `ok` / `checked_by` / `checked_date` / `note` | 同上 | |

※「登場話数」は、**登場する話**(予告・回想のみの話は含めない等)の基準を、`note` に書いておく。基準が分かれる話があれば、第10章の `[[CHECK]]` にも反映する。

## 4. 取り込みの手順
```bash
python3 build/import_entry.py --dry-run     # 検査だけ(何も書き込まない)。エラーがあれば表示される
python3 build/import_entry.py               # atlas と figures.csv に反映
python3 build/validate.py                   # atlas の検査
python3 build/figs.py                       # 話数カード・図を再生成
python3 build/checks.py                     # 残りの確認の印を一覧
```
- 何度でも取り込める。**○を外すと、その行は下書きに戻る**。
- 取り込み後は、確認済み(○)の行の `[[CHECK]]` の印が atlas から消える。
- 話数カードは、**その話の使徒がすべて確認済み**で、かつ**その話が確認済み**のときだけ、「DRAFT・未確認」の透かしが外れる。
- 最新の状態を表に戻したいときは `python3 build/export_entry.py`(**未取り込みの記入は上書きされる**ので注意)。

## 5. 文字コード
CSVは **UTF-8(BOMつき)**。Excelで開いてそのまま保存すれば、文字化けしない。Googleスプレッドシートは「ファイル→インポート」で読み込み、「CSVとしてダウンロード」で書き出す。

## 6. 書式の例(架空の書き方の例。内容は実際のデータではない)
| 列 | 書き方の例 |
|---|---|
| `sorties` | `機体名(搭乗者);機体名(搭乗者)` |
| `focus` | `人物名;人物名` または `ch-shinji;ch-rei` |
| `reveals` | `設定A;設定B` |
| `version_note` | `-`(差なし)/ `短い説明`(差あり) |
