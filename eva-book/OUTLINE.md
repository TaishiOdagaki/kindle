# 章立て v0.2(目標 約13.5万語。`chapters.csv` が進捗の正)

**本書の背骨(C案・推奨)**: エヴァは「他者との接触」という同じ問いに、TV版・旧劇場版・新劇場版でそれぞれ違う答えを出した。その答えの変化は、庵野秀明と観客との26年の関係の変化と重なって読める。
※この論旨は**仮説**。各章で証拠を積み、通らなければ修正する。

## 設計ルール
- 第1〜15章+巻末は**新作に影響されない本体**。**新作の影響は c19 / fm2 / b01 / b03 のみ**。
- 各章は冒頭に「この章の範囲(ネタバレの有無)」、末尾に「次に読む章」を置く。
- 各章の「証拠」は、事実DBまたは出典リストに紐づける。

## 新作の続報があったときの更新手順
1. 公式発表を `data/facts/works.csv` に日付つきで追加(`verified=yes`)
2. c19 を更新(確定情報のみ。推測は **Interpreted** と明記)
3. fm2 / b01 / b03 の該当箇所を更新
4. `python3 build/build.py --release` → KDPで更新版を公開
