# 図表の方針と計画(v0.1)

**方針(2026-10-05 決定)**: 図表・グラフを**できるだけ多く**盛り込む。解説書として、文章だけでは伝わりにくい構造(時系列、関係、比較、設定の仕組み)を、図で見せる。
※「チェンソーマン英語版のように」という参照先の具体的な本・体裁は未確認。特定の体裁の指定があれば、このファイルの「体裁」を更新する。

色・様式は [`design/DESIGN.md`](design/DESIGN.md) の定義に従う(巻ごとのイメージカラー: 赤・黄・青)。

## 1. 守るルール
| 項目 | ルール |
|---|---|
| **図は自作のみ** | 作中の画像、スクリーンショット、キャラクターの絵、設定画、ロゴは**使わない**。図は本書のために新しく作った図表・図解に限る |
| 書体・配色 | 作品の**タイトルカード風の書体や配色を模倣しない**(公式と誤認される恐れ。PROJECT_BRIEF §5)。IPAexゴシックなど、無関係な書体を使う |
| データの出どころ | 図は**atlas のデータから生成**する(使徒の登場話数など)。手描きの数値を図にだけ書かない |
| 確認ゲート | `figures.csv` の `verified` が `yes` でない図は **「DRAFT・未確認」の透かし**が入り、**リリースビルドが失敗**する |
| 概念図の表示 | 筆者の整理を含む図は、図中に「概念図(筆者の整理)」と明記する |
| 電子ペーパー対応 | **グレースケールだけで読める**(色に意味を持たせない。線種・濃淡・記号で区別)。文字は大きく(幅1600pxで11pt以上)|
| 代替テキスト | 全図に、内容を説明する代替テキスト(`alt`)を付ける。日英別 |
| 本文での言及 | すべての図は、本文で**言及**し、その図が何を示すかを1文で述べる |
| 1図1メッセージ | 1つの図で言うことは1つ。複雑な場合は図を分ける |

## 2. 図の種類と使いどころ
| 種類 | 使う場所 | 例 |
|---|---|---|
| **話数カード**(定型の1枚図解) | 各話ガイド(全26話) | 話数/登場する使徒/出撃した機体/中心人物/新たに明かされる設定/版による差 |
| **タイムライン** | 背景、制作史、作中年表、公開史、英語圏流通史 | 制作〜放映、1995〜2021年の公開年表、セカンドインパクト〜2015年 |
| **グラフ**(話数軸) | TV版、設定の章 | 使徒×話数(作成済)、人物の登場話数、設定が明かされる話数(作成済) |
| **関係図・組織図** | 世界設定、人物 | ネルフの組織図(作成済)、人物相関図(時期別に3〜4枚) |
| **概念図・構造図** | 設定、結末、主題 | エヴァの搭乗と動力(作成済)、二つの計画(作成済)、TV25–26話と旧劇の構造対照、ATフィールドの二重の意味 |
| **比較表・マトリクス** | 旧劇・新劇、三作比較 | 人物・設定・場面・結末のTV/旧劇/新劇の対照 |
| **論点マップ** | 論争の章 | 各論点での立場の分布(誰がどの立場か) |
| **受容・データのグラフ** | 現象、英語圏の章 | 公開後の関心の推移(出典つきの公開データのみ) |
| **凡例・読み方の図** | 前付 | 証拠の三つのラベル(作成済) |

## 4. 作り方
- 図は `build/figs.py` の関数として定義し、`figures.csv`(ID・キャプション・代替テキスト・検証状態)に登録する。
- 原稿には **`{{fig:図のID}}`** と書く。ビルド時に、「図2-1 題名」の形で**章ごとに自動採番**される。
- 再生成: `python3 build/figs.py --lang=both`(日本語・英語の両方)。出力は `build/img/`(自動生成物。Gitには入れない)。
- 英語版: 同じ関数が、ラベルを英語に切り替えて出力する(`t(日本語, 英語)` の形で両方を書く)。

## 5. 表について
- 短い表(4列以内・各セルが短い)は、**文章中のMarkdownの表**にする(Kindleの文字サイズ変更に追従する)。
- 幅の広い表・長い表は、**画像にする**(電子ペーパーで崩れるのを避けるため)。その場合も、情報は atlas に残す。

## 6. Kindleでの注意
- 画像は**幅1600px・PNG**。縦長の図は避ける(画面1枚に収める)。
- **ファイルサイズ**: 図を多用すると巻のサイズが増える。KDPの配信コスト(ロイヤリティ70%では、ファイルサイズに応じた配信コストが差し引かれる場合がある)の**現行条件を、入力画面で確認する**。目安として、1巻の画像の合計を **20MB以内**に収める。
- Kindleの文字サイズ変更に図が追従しないため、図中の文字は大きめにする。
