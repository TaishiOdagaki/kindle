# 資料と検証手順(v0.1)

## 資料の優先順位
1. **作品そのもの**(TV版、旧劇場版、新劇場版を全話・全編視聴。台詞・描写は**視聴して**確認)
2. **公式資料**(公式サイト、公式発表、公式パンフレット、公式の設定資料集・ガイド)
3. **制作者の発言の一次記録**(当時の雑誌インタビュー、公式の対談・コメント、DVD/BDの特典・ブックレット)
4. **信頼できる報道**(日本語・英語の主要媒体。**日付と署名を確認**)
5. **研究書・批評**(学術書、評論。著者名・出版年・出版社を記録)
6. **ファンサイト・Wiki**(**事実の根拠にしない**。手がかりとしてのみ使い、必ず1〜4で裏づける)

## 検証の流れ
1. 事実を atlas の該当項目(例: `atlas/episodes/ep-01.md`)に書く(題名、放映日など)
2. 出典を `sources:` に記入する(出典自体も `atlas/sources/` の1項目にする)
3. 一次資料で確認できたら `status: verified` にする(`build/validate.py` が条件を検査)
4. 本文で断定して使えるのは `verified` のもののみ
5. 確認できない説は **Interpreted** として、誰の説かを明記して扱う

## 日本語資料の扱い
- 日本語の記事・書籍は、**書名・出版社・刊行年を正確に記録**して参考文献に載せる(`data/jp_unofficial_books.csv` の10タイトルは、書名等が未検証)。
- 長い引用はせず、**自前の要約・翻訳**で扱う。
- 英語読者が追えるよう、日本語資料の書誌には**英訳した題**を付ける。

## 取得が必要な資料(着手順)
- [ ] 全話・全編の視聴メモ(各話の事実DB入力)
- [ ] 公式の各話題名・放映日・公開日の確定(atlas の `ep-*` / `work-*`)
- [ ] 旧作時代の制作者インタビューの出典リスト(雑誌名・号)※一次資料の所在確認が必要
- [ ] 新劇場版期の公式パンフレット等
- [ ] 新作の公式発表(随時、日付つきで記録)
- [ ] 英語圏での受容(当時の英語圏レビュー・放映の経緯)
