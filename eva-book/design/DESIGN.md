# デザイン仕様(v0.1)

本書のデザインは、`design/tokens.yaml` に定義した**トークン**から、図・話数カード・表紙・EPUBのCSSをすべて自動生成する。色や書体を変えるときは、トークンだけを書き換える。

## 1. 巻のイメージカラー(2026-10-05 決定: 赤・黄・青)
| 巻 | 色 | 塗り(アクセント) | 文字・線用(白地) | 淡色(塗り) | 塗りの上の文字 |
|---|---|---|---|---|---|
| 第1巻 背景とTVシリーズ | **赤** | `#B5282E` | `#B5282E` | `#F2D8D9` | 白 |
| 第2巻 旧劇場版と新劇場版 | **黄** | `#E3B100` | `#8A6500`(濃い黄) | `#FAF1D1` | **黒** |
| 第3巻 解釈・英語圏・FAQ | **青** | `#1B3F7A` | `#1B3F7A` | `#D6DCE7` | 白 |

**選定の理由**: 三原色は特定の作品の配色ではなく、公式との誤認の恐れがない。3色はグレースケールで**濃い灰・明るい灰・中間の灰**にきれいに分かれ、電子ペーパーでも巻を識別できる(下表)。
**検討して採らなかった案**: 作品の機体色を巻に当てる案(公式の関連商品と誤認される恐れ、巻の内容と色が食い違う、紫と赤がグレースケールで近い)、藍・琥珀・納戸の落ち着いた配色(第1・第2巻が暗く近い)。プレビュー: `design/preview-color-options.png`。

**黄色の扱い**: 黄は白地の上で視認しにくい(コントラスト約1.9)。そのため、第2巻では、**塗り**には黄(`#E3B100`、上の文字は黒)、**白地の上の文字・線・棒グラフ**には濃い黄(`#8A6500`)を使う。

## 2. 色の運用ルール
1. **色だけに意味を持たせない**。電子ペーパー(グレースケール)で読めるように、線種(実線/破線)、濃淡、記号(●■▲)、ラベルで同じ情報を二重に示す。
2. 巻の色は**識別のため**(表紙、章扉、見出し、図の強調、話数カードの帯)。本文の意味(例: 描写/発言/解釈)の区別には使わない。
3. 塗りの上の文字は、コントラスト比 **4.5以上**。白地の上の文字・線は、**濃い色(`accent_dark`)で4.5以上**。
4. 3巻の塗りは、グレースケールにしたとき**明度が0.03以上離れる**。表紙は、さらに**モチーフ**(第1巻: 波紋、第2巻: 重なる二つの輪、第3巻: 星座状のつながり)で識別する。

検査: `python3 build/design_check.py`(基準を満たさないと失敗する)。

| 巻 | 塗りの上の文字のコントラスト | 淡色上の文字のコントラスト | 塗りの明度 | グレースケールでの色 |
|---|---|---|---|---|
| 1 赤 | 6.35 | 14.03 | 0.115 | `#606060` |
| 2 黄 | 9.49 | 16.70 | 0.478 | `#b6b6b6` |
| 3 青 | 10.30 | 13.71 | 0.052 | `#424242` |

## 3. 様式の一覧
| 様式 | 内容 | 生成元 |
|---|---|---|
| **図・グラフ・概念図** | 巻の色で強調。薄い塗りは淡色。キャプションは「図N-k」で自動採番 | `build/figs.py` |
| **話数カード** | 左に巻色の帯(話数)、右に題名・使徒・出撃・中心人物・明かされる設定・版による差 | `build/figs.py` + atlas `ep-NN` |
| **表紙** | 巻色の全面+モチーフ+題名+巻番号。**作品の画像・ロゴ・書体は使わない**(仮デザイン) | `build/cover.py` |
| **EPUBのスタイル** | 章見出しの下線、節見出しの縦線、まとめ枠(淡色)、表の見出し行(巻色)、図の中央寄せ | `build/design.py` |

## 4. 話数カードの項目(=視聴確認で記入するデータ)
| 項目 | atlas のフィールド(`atlas/episodes/ep-NN.md`) | 備考 |
|---|---|---|
| 話数・題名 | `number` `title_jp` `title_en` | 題名は現在、**記憶による仮入力**(未確認) |
| 放映日 | `air_date_jp` | |
| 使徒 | (使徒データ `an-*` の `episodes` から自動) | |
| 出撃 | `sorties`(例: `初号機(碇シンジ)`) | リスト |
| 中心人物 | `focus`(人物ID。例: `ch-shinji`) | リスト |
| 明かされる設定 | `reveals` | リスト |
| 版による差 | `version_note` | 文字列 |

フィールドを埋めて `python3 build/figs.py` を実行すると、カードに反映される。

## 5. 変更したいとき
- 色: `design/tokens.yaml` の `accent` / `accent_dark` / `tint` / `on_accent` を編集 → `python3 build/design_check.py`。
- 図のサイズ・書体: `tokens.yaml` の `figure` / `typography`。
- 表紙: `build/cover.py`(最終版の表紙は、デザイナーの制作または別途の独自デザインに置き換える)。
