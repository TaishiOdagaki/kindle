# 【日本語の喜び・第1回】信号機は、なぜ「青」なのか

初級クラスで、必ずと言っていいほど聞かれる質問がある。

「先生、信号、緑なのに、どうして『青』信号なんですか」

毎年、誰かしらが聞いてくる。そのたびに、この話をしている。

## 「青」は、もともと緑も含んでいた

昔の日本語には、色を表す基本的な言葉が今よりずっと少なかった。赤、黒、白、そして青。この4つが、いちばん古くからある基本の色の言葉だと言われている。

緑という色は、長いあいだ「青」の仲間として扱われていた。青葉、青虫、青りんご。今でも緑色のものを「青」と呼ぶ言葉が、驚くほど残っている。

信号機が日本に入ってきたとき、「緑信号」ではなく「青信号」と呼ばれたのも、この名残らしい。

## しかも、信号の色自体を「青く」寄せている

ここからが、たぶん日本人でも知らない人のほうが多い話だ。

日本の交通信号の「進め」の色は、青色寄りの緑色にするよう決められている。「青」と呼ぶ以上、できるだけ青く見える色を使おう、という発想らしい。

つまり、呼び方に合わせて、信号の色そのものを調整している。言葉が先で、現実がそれに寄せられた、という珍しいパターンだ。

## 学生に教えると、たいてい驚かれる

この話をすると、学生はたいてい「え、そうなんですか」という顔をする。母語で「緑」と習ってきたものが、日本語では堂々と「青」と呼ばれているのだから、無理もない。

言葉というのは、目の前の現実をそのまま写し取っているわけではない。むしろ、昔の分け方の名残を、律儀に引きずっていることのほうが多い。

信号を見るたびに、その名残を渡っている気分になる。
