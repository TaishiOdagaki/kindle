# 「やばい」が褒め言葉にも悪口にもなる、日本語の自由さ

前回、「どうも」のように、意味よりも場の空気を整える機能だけで生きている言葉があるという話を書いた。似たような不思議さを持つ言葉が、もう一つある。

「やばい」だ。

## 良い意味にも、悪い意味にも使える

「このラーメン、やばい」と言われたとき、おいしいのかひどいのか、文脈なしでは判断できない。

元々は危険や不都合を表す、完全にネガティブな言葉だった。それが今では、感動するほど美味しい、信じられないほど綺麗、笑ってしまうほど面白い、というポジティブな意味でも、同じ一語で使われている。

学習者からよく聞かれる。「先生、『やばい』はいい意味ですか、悪い意味ですか」。答えはいつも同じだ。「両方です。文脈と、言い方のトーンで判断してください」。

## トーンとテンションが、意味そのものになっている

ここが日本語の面白いところだと思う。「やばい」の意味を決めているのは、単語そのものではなく、声の高さ、表情、前後の文脈という、言葉の外側にある情報だ。

同じ「やばい」でも、目を見開いて声が高くなれば褒め言葉になり、顔をしかめて声が低くなれば、まずい状況を表す。単語の意味を辞書的に固定できず、使われ方そのものが意味を作っている。

これは、文法的には説明しづらいけれど、ネイティブは子供の頃から自然に区別している感覚だ。改めて考えると、結構すごいことをやっている。

## 「やばい」は、感情の強さだけを運ぶ言葉になった

突き詰めると、「やばい」は今、良い悪いの方向性を離れて、感情が強く動いたという事実だけを伝える言葉に近づいている気がする。

喜びでも、驚きでも、恐怖でも、感動でも、「何かすごく感情が動いた」という一点さえ共通していれば、この一語で足りてしまう。方向性は、残りの文脈に委ねる。

言葉というのは、放っておくと、こういう風に意味の輪郭がだんだん緩くなっていくものなのかもしれない。それを「乱れ」と見るか、「言葉の自然な進化」と見るかは、人によって分かれるところだと思う。個人的には、後者の方が面白く感じる。
