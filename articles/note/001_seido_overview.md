# 登録日本語教員ってそもそも何？迷ったらまずここを整理しよう

はじめまして、薫です。関西のとある日本語学校で15年ほど教壇に立っている。長くやっているわりに、新しい制度の名前が出てくるとやっぱり身構えてしまうのだけれど、今回はその代表格、「登録日本語教員」について書いてみる。

「登録日本語教員」という言葉を聞いて、正直ピンときていない人も多いと思う。私自身、最初に耳にしたときは「日本語教育能力検定試験と何が違うんだろう」というところから始まった。15年もやっていて何を今さら、と我ながら思ったけれど、制度というのは経験年数を容赦なく無視してくる。

この記事では、制度の細かい条文の話ではなく、「受験を考えている人がまず押さえておきたい全体像」を整理する。細かい要件や最新のスケジュールは変更されることがあるので、最終的には必ず文化庁の公式情報で確認してほしい。ここではその前提となる「地図」を渡すつもりで書く。

## そもそもどういう資格なのか

登録日本語教員は、日本語教育機関で日本語を教えるために必要になる国家資格として新しく作られた。これまでは日本語教師になるための道筋が「日本語教育能力検定試験に合格する」「養成講座420時間を修了する」「大学等で主専攻・副専攻を修めた」など複数あり、機関によって求められる要件もまちまちだった。

登録日本語教員は、この状態を整理し、一定の水準を国として保証する資格に位置づけられている。法務省告示校（留学生を受け入れる日本語学校）で教えるためには、今後この資格が必須になっていく流れにある。

## 「経過措置」という言葉の意味

制度の話でよく出てくるのが「経過措置」という言葉だ。これは、すでに現場で教えている人や、日本語教育能力検定試験に合格している人などを対象に、一定の条件のもとで試験の一部（または全部）が免除される仕組みを指す。

自分がどの経過措置の対象になるかによって、

- 基礎試験・応用試験の両方を受ける必要があるのか
- 一部の試験が免除されるのか
- 免除の代わりに何らかの研修や実践研修が必要になるのか

が変わってくる。ここを勘違いしたまま勉強を始めると、不要な範囲まで手を広げてしまったり、逆に必要な対策が漏れてしまったりする。まず最初にやるべきなのは、参考書を開くことではなく「自分がどの経過措置区分に該当するか」を公式情報で確認することだと思う。

## 試験の大きな構成

試験は大きく「基礎試験」と「応用試験」に分かれている。

基礎試験は、日本語教育に関する基礎的な知識を問う内容で、これまでの日本語教育能力検定試験と重なる部分も多い。応用試験は、読解・聴解・音声の各領域から、より実践的な場面での判断力や知識の応用力を問われる構成になっている。

「基礎試験に受かれば終わり」ではなく、応用試験まで見据えて学習範囲を組み立てる必要がある、というのが最初につまずきやすいポイントだと感じている。
