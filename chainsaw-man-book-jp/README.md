# チェンソーマン：デビル・イン・ザ・ディーテイルズ（日本語版）

`chainsaw-man-book/`（英語版 *Chainsaw Man: The Devil in the Details*）の日本語版。単純な翻訳ではなく、「海外のファンに向けて日本人が英語で書いた批評本が、逆輸入で日本語になった」という体裁の別プロジェクトとして作られている。2026年9月28日、劇場版『チェンソーマン レゼ篇』がAmazon Prime Videoで独占配信を始め、日本国内で話題になったことがきっかけで企画された。

## 英語版からの主な変更点

- **タイトル**: 当初は日本語の慣用句「神は細部に宿る」を踏まえた地口として「悪魔は細部に宿る」を提案したが、最終的にユーザーの判断で「チェンソーマン：デビル・イン・ザ・ディーテイルズ」（英語タイトルの音訳、カバーは英語タイトルと並記）に確定。地口は採用されなかった — シリーズとしての一貫性・カバーとの統一を優先した判断。
- **サブタイトル／著者紹介**: サブタイトルは「逆輸入！ 世界中のファンのために いま明かされるチェーンソーマンの秘密」に確定（ユーザー案）。著者紹介は、もともと海外読者向けに英語で書かれたものが日本語話者にも届くよう訳し直された、という文脈を明記。
- **イントロダクション**: 英語版で「Western読者にとっての異色の入口」「日本の漫画で例える、西洋の漫画ではなく」と書かれていた、海外読者限定の内容を、日本語話者にはそのまま成立しない箇所としてカットまたは書き換え。代わりに「もともと海外読者向けに書かれた本だからこそ見える、日本人読者が普段意識しない要素」という視点を追加。
- **第2章**: 「日本人読者と海外読者とで読み方がどう違うか」という段落は、削除ではなく、逆輸入という企画全体のテーマに接続する形で残した（この本自体が、その「届かない部分」を埋めるために書かれた、という一文を追加）。
- **第13章「WHAT GETS LOST IN TRANSLATION」（英訳で失われるニュアンスの章）は、日本語版では丸ごと差し替え。** 日本語話者には成立しないテーマだったため、代わりに劇場版『レゼ篇』のPrime Video独占配信と、それに伴うプロモーション（花江夏樹の応援動画、新宿駅メトロプロムナードのサメ映画風展示）を扱う、日本語版オリジナルのボーナス章にした。事実関係はWebSearchで複数媒体を突き合わせて確認済み（配信開始日、興行収入、藤本タツキ本人のコメントなど）。
- それ以外の全14章は、既存の分析内容をそのまま翻訳。第9章の漫才リズムの話や、第5章の映画的コマ割りの話など、日本語読者にとっても新鮮に読めると判断した箇所はそのまま残した。
