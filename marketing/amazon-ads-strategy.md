# 「登録日本語教員試験問題集」Amazon Ads 販促戦略

## 0. 前提の整理

- **商品**: Kindle出版済みの「登録日本語教員試験問題集」
- **市場背景**: 2024年度から始まった国家資格「登録日本語教員」試験（日本語教育の新制度）向けの過去問・演習問題集。対象試験自体が新しく、参考書市場の競合がまだ少ない今がSEO・広告的に有利なタイミング。
- **想定読者**:
  - 現職の日本語学校教師（経過措置対象者含む）で資格切替のため受験する層
  - 日本語教育能力検定試験合格者で登録日本語教員へのルート変更を検討する層
  - 日本語教師を目指す社会人・大学生（養成講座修了ルート以外で受験する層）
- **収益モデル・現状の設定**
  - 通常価格: ¥1,500
  - 期間限定セール価格: ¥750（半額）※商品説明欄に「期間限定」である旨を明記
  - ロイヤリティプラン: 75%（※KDPの標準ロイヤリティオプションは35%／70%の2種類のため、設定画面の表示を一度ご確認ください。以下は頂いた75%の数値で計算しています）
  - KDPセレクト登録: 済み（Kindle Unlimitedの既読ページ収益＝KENPが発生）
  - レビュー: 現状0件 → 広告のCVR（購入転換率）に直接影響するため、後述の通り最優先で対策する

### 損益分岐ACOSの考え方
```
損益分岐ACOS(%) = 印税単価 ÷ 販売価格 × 100
```
配送コスト（ファイルサイズに応じた実費、通常は数円〜十数円程度）を無視した概算では、印税率が一定なら価格が変わっても損益分岐ACOS(%)は理論上ほぼ同じになる。

- **通常価格 ¥1,500・印税75%**: 印税単価 ≒ ¥1,125 → 損益分岐ACOS ≒ **75%**
- **セール価格 ¥750・印税75%**: 印税単価 ≒ ¥562.5 → 損益分岐ACOS ≒ **75%**
  （実際には配送コストが一定額のため、価格が半分になるとその実費負担割合が相対的に増え、セール中の実質損益分岐ACOSはこれよりやや低くなる点に注意）

75%という損益分岐ACOSはかなり高い＝広告費をかけられる余地が大きいことを意味するが、これは「単発の1冊売れた分だけで採算を取る」場合の理論値。レビュー0件・新刊という状況ではCVRが低く出やすいため、**実際の運用目標ACOSは損益分岐点よりかなり保守的な水準（下記3章参照）に置く**のが安全。KENP（Unlimited既読）収益は広告経由でも発生しうるため、TACOSで見ればさらに許容度は上がる。

## 1. 出稿前にやるべき土台固め（Ads着手前チェックリスト）

広告は「良いターゲティングで悪い商品ページに送る」と成果が出ない。まずKDP側のメタデータを最適化してからAdsを回す。

1. **タイトル・サブタイトル**: 検索されるキーワードを自然に含める
   - 例:「登録日本語教員試験 問題集｜過去問・予想問題で合格対策」
2. **7つのバックエンドキーワード（KDP設定）**: 広告のキーワード候補と重複してよい。以下を検討。
   - 登録日本語教員
   - 日本語教育能力検定試験
   - 日本語教師 資格
   - 日本語教員 試験対策
   - 日本語教育 国家資格
   - 経過措置 日本語教員
   - 日本語教師 独学
3. **カテゴリ選定**: 資格・検定、教育、語学関連の複数カテゴリに登録し、ベストセラーランキング獲得の可能性を上げる。
4. **表紙・商品説明（A+コンテンツ的な工夫）**: 表紙に「登録日本語教員試験対応」「〇〇問収録」等のベネフィットを明記。説明文の冒頭3行で「誰のための本か」「何が得られるか」を明示（広告経由の初見読者はここで離脱判定する）。
5. **価格とUnlimited設定**: KDPセレクト登録済み・参考書ジャンルはUnlimited読者比率が高い傾向なので方向性は合っている。
6. **レビュー（現状0件・最優先課題）**: レビュー0件のまま広告クリックを集めても、商品ページで離脱されCVRが伸びない。広告を本格的に増額する前に、以下でまず数件〜10件のレビューを獲得する。
   - KDPセレクトの**無料本プロモーション**（90日ごとに最大5日間、価格を¥0にできる特典）を広告開始と同時期に実施し、ダウンロード数を増やして自然なレビュー獲得の母数を作る
   - 巻末に「役に立ったら感想・レビューをお願いします」という一文を追加（Amazon規約上、レビューを条件に金銭や物品を提供するのはNGだが、感想を依頼すること自体は問題ない）
   - 既存のnote/SNSフォロワーや日本語教師コミュニティに献本・試読を呼びかけ、購入者に感想投稿を依頼
   - レビューが5件以上つくまでは、手動キーワード広告の予算は小さめに保ち、無料プロモーションと自然流入でのレビュー獲得を優先する

## 2. キャンペーン構成（Amazon Ads / KDPのAdsダッシュボード）

KDP本の広告は Amazon Advertising の「スポンサープロダクト広告（Sponsored Products）」が基本。段階的に3種類を併用する。

### Phase 1（1〜2週目）: オートターゲティング + 幅広収集
- **キャンペーンA: オート型**
  - 目的: どんな検索語・商品で表示されているかのデータ収集
  - 予算: 日予算 ¥500〜1,000程度からスタート
  - 入札戦略: 「動的-ダウンのみ」（低リスク）
  - 4つのターゲティンググループ（близ合致/緩い合致/代替商品/補完商品）は自動で全て有効化

### Phase 2（並行して開始）: 手動キーワードターゲティング
- **キャンペーンB: 手動・完全一致（フレーズ/完全一致）**
  - コアキーワード（購買意欲が高い＝コンバージョン狙い）
    - 登録日本語教員 試験対策
    - 登録日本語教員 問題集
    - 日本語教育能力検定試験 過去問
    - 日本語教員 試験 テキスト
    - 日本語教師 資格 独学
  - 入札: オート広告のデータが出るまでは相場観として¥40〜80程度で開始し、インプレッションが極端に少なければ引き上げ

- **キャンペーンC: 手動・フレーズ一致（拡張・発見用）**
  - より広いテーマ語
    - 日本語教師 なるには
    - 日本語教育 資格
    - 外国人 日本語 教える 資格

### Phase 3（3週目以降）: プロダクト（商品）ターゲティング
- **キャンペーンD: 商品ターゲティング**
  - 競合書籍のASINを直接指定（類書、日本語教育能力検定試験の問題集、日本語教授法の入門書など）
  - カテゴリターゲティング（「日本語教育」「語学資格・検定」カテゴリ）
  - 狙い: 類書を検索・閲覧しているユーザーの商品ページに割り込み表示

### 除外設定
- オート広告の検索語句レポートから、無関係な検索語（例:「日本語 勉強アプリ」等コンバージョンしない広い語）を随時ネガティブキーワード化
- 自社の他タイトルがあれば、共食い防止のため必要に応じて除外調整

## 3. 運用サイクル（PDCA）

| 頻度 | 作業 |
|---|---|
| 毎日〜隔日（最初の2週間） | インプレッション・クリック有無の確認、極端な予算枯渇や入札不足がないかチェック |
| 週次 | 検索語句レポートを確認し、①コンバージョンした語を手動キャンペーンへ「昇格」、②無駄クリックの語をネガティブ化 |
| 週次 | ACOS・CVR・CTRをキャンペーン別に確認し、入札額を5〜15%刻みで微調整（急激な変更をしない） |
| 隔週 | 商品ページのレビュー数・評価・表紙/説明文のA/B的見直し |
| 月次 | 損益分岐ACOSと実績ACOS＋KENP収益を合算したTACOSで採算判定。赤字が続くキャンペーンは停止・再設計 |

### 主要KPIの目安（参考値。実データで随時更新）
- **CTR**: 0.3%以上を目安（資格書籍ジャンルは検索意図が明確なため比較的高CTRが出やすい）
- **CVR**: レビュー0件のうちは通常より低め（5%未満も想定内）に出やすい。レビューが増えるにつれて改善を見込む
- **目標ACOS**:
  - 損益分岐ACOSは約75%と高めだが、レビュー0件のうちはこれを鵜呑みにせず**目標ACOSを40〜50%程度**に抑え、日予算の上限で下振れリスクをコントロールする
  - レビューが5〜10件以上つき、CVRの実績値が安定してきたら、目標ACOSを損益分岐ACOSの70〜80%程度まで段階的に引き上げてよい

## 4. 広告以外で相乗効果を出す施策（TACOS改善）

広告費だけに頼らず自然流入・指名検索を増やすことで、広告に頼らない売上比率（TACOS改善）を高める。

1. **SNS・note・X**: 「登録日本語教員試験」で検索してくる層に向けて、試験制度の解説記事や勉強法noteを書き、本への導線を張る（既存noteアカウントの資産を活用可能）。
2. **日本語教師コミュニティ**: SNSの日本語教師クラスタ、日本語学校の掲示板・Facebookグループなどでの告知（過度な宣伝にならない範囲で）。
3. **無料/割引キャンペーンの活用**: 今回のように手動で期間限定の半額（¥1,500→¥750）にする施策に加え、KDPセレクトの無料本プロモーション（90日間で最大5日間・価格¥0）も組み合わせ、レビューと初速ランキングを稼いでから広告を強化するタイミングを合わせる。（Kindle Countdown Dealsは日本のマーケットプレイスでは提供されていないため、価格変更は手動で行う）
4. **シリーズ化**: 分野別（文法/音声学/異文化理解 等）に分冊展開できれば、Sponsored Brands（複数タイトルが条件）が使えるようになり、ブランド名（著者名）での指名検索広告も可能になる。

## 5. 実行スケジュール（最初の4週間）

- **week 1**:
  - KDPメタデータ最適化、商品説明欄に「期間限定¥750（通常¥1,500）」のセール表記を追加
  - 巻末にレビュー依頼文を追加
  - オート広告1本を少額（日予算¥500〜1,000）で開始し、データ収集開始
  - 目標ACOSは40〜50%の保守的な水準に設定（レビュー0件のため）
- **week 2**:
  - 検索語句データが貯まり次第、手動完全一致キャンペーンを追加。ネガティブキーワードの初回整理
  - セール価格¥750が有効な期間はCVRが上がりやすいため、この期間中に日予算を通常より積み増して販売数・レビュー数を稼ぐ好機と位置づける
- **week 3**:
  - 商品ターゲティングキャンペーンを追加。ACOSレビューと入札調整を開始
  - セール終了・価格が¥1,500に戻るタイミングでは、CVR低下を見込んで入札額・日予算を一段階下げて様子見する
- **week 4**:
  - 月次採算判定。レビュー件数の推移とCVRの変化を確認し、目標ACOSを損益分岐ACOS（約75%）に近づけて良いか判断
  - TACOS視点（KENP収益も合算）で広告予算の増減を決定し、伸びているキーワード/商品ターゲットに予算を寄せる

## 6. 今後の詳細化に向けて引き続き確認したいこと

- 出版からの経過日数、現状のオーガニックな販売数・KENP既読ページ数
- 想定している「期間限定」セールの具体的な開始日・終了日（広告予算の増減タイミングに合わせるため）
- 競合となりうる類書のASIN（商品ターゲティング広告で直接指定する候補）
- Amazon Adsをすでに一部運用している場合はその実績データ（ACOS, CTR, CVR等）
