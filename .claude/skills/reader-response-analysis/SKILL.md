# 読者反応分析 v0.1

## 事前に読むもの
- `docs/writing-lab-integration.md` と `research/note-performance.csv`
- `personas/note_account_concept.md` と `.claude/skills/humanize-writing/SKILL.md`
- `TaishiOdagaki/japanese-writing-lab` の `AGENTS.md` と `docs/field-study-note-kindle.md`（アクセス可能なとき）

## 必須手順
1. 利用者が許可したデータだけを読み、取得時刻、出典、計測期間と欠損を記録する。公開数字を捏造・穴埋めしない。
2. 記事をエッセイ / 日本語論 / 試験情報 / 宣伝などに分類し、ジャンルと公開後日数を揃えて比較。
3. 露出（表示回数）、閲覧（PV）、反応（スキ）、販売（有料注文・KENP・無料取得）を混同しない。PV/表示回数は公式CTRではない。
4. 観察 → 仮説 → 交絡要因・反例 → 次の一回の変更案、の順に短く報告。クリックされるタイトルと有料転換する記事は異なる可能性がある。
5. タイトル案は本文に対応させる。刺激的な動詞を成果保証の定型として使わない。
6. 実体験のように見える記述は本人確認済みの体験だけ。設定された架空の逸話は実話と称さない。
7. 効果の検証前に一般技法へ昇格しない。研究所に渡すのはジャンル・証拠・反例・適用条件を含む要約のみ。
