# 問題集の校正手順

誤りは見つけたら必ずここに足していく。

## 1. 機械検査(必ず最初に)
`python3 tools/quiz_audit.py 本.docx`

| コード | 意味 | 過去に見つかった例 |
|---|---|---|
| S1〜S4 | 選択肢が4つ・設問文の文末・正誤タグの形式 | |
| S3 | 選択肢に設問文が混入 | 設問文が「1.」に入り、選択肢が1つずれた(26問) |
| D1 | 選択肢が1つずれて解説と対応 | 同上。恒等対応より1つずれ対応の類似度が高い |
| D2 | 解説の並びが入れ替わっている疑い | 模擬試験53の解説1と2が入れ替わっていた |
| P1 | (正)の解説が否定文で終わる | 正解番号が間違っていた(応用ケース3問4) |
| S5 | 早見表と解説の正解が不一致 | |
| T1〜T5 | 不可視文字・重複表記・同字連続・既知の誤植・空白 | 「答答」「複号的」「正義文」など |
| V1 | 表記ゆれ(辞書は`VARIANTS`) | 情意/情緒的フィルター、JF標準/スタンダード |
| X1 | 解説が「選択肢N」を参照 | 並べ替えで壊れる |
| A1 | 正解だけ断定語がある(弱い指標、人が確認) | 誤検出が多い |

D2・P1・A1は疑いの検出であり、誤検出がある。必ず該当問を読んで判断する。

## 2. 統計で偏りを見る(統計は検査の最後に出る)
- 正解位置が各25%前後か。v2は1が41%・2が42%・4が2%、模擬試験は全問「1」だった。
- 正解が最長の選択肢の割合(無作為なら25%)。v2は72%。偏りがあれば、短い選択肢を具体化するか、誤答を同じ長さに揃える。
- 位置の偏りは`tools/shuffle_options.py`で直せる。
- 長さの偏りは`tools/rewrite_long_keys.py`の辞書(問題ID→選択肢番号→本文)に書き足して直す。正解は意味を変えず短く、誤答は主張を変えず根拠を足して長くする。正解÷他の最長が1.4を超える問題を洗い出し、直した後は解説との対応を再検査する。
- 正解が最長の問題が多いときは `tools/r3/` を使う。`batchN.py` に `B = {問題ID: {選択肢番号: 新しい本文}}` を書き、`python3 tools/r3/apply.py 入力.docx 出力.docx` で適用する(正解より長くならなかった問題が一覧で出るので、`batchNb.py` で追補する)。`_h.py` の `R(問題ID, 番号, 元の語句, 新しい語句)` は原文の一部を置き換える。
  - 誤答を足す文は必ず読み直す。語尾を機械的に継ぎ足すと「であるであり」「ためため」のような不自然な日本語になる(今回、実際に起きて全部書き直した)。
  - 全問で誤答を正解より少しだけ長くすると、正解が2番目に長い問題が約7割になり、別の手がかりになる。差が小さかった問題は元に戻す(`batch9_revert.py` の `REVERT`)。最終的に最長・2番目・それ以下がばらけているかを、順位の分布で確認する。
- 用語を答える問題は、正解にだけ括弧書きの補足があると目立つ。誤答にも同じ形式で補足を付けて揃える。

## 3. 人が読む検査
- 設問と選択肢と解説の三者が対応しているか。(正)の解説が本当に正しい記述か。
- 例文や会話が設問の指示と合っているか(例: 「貸していただいた」の例で「させていただく」を問う)。
- 選択肢2つが同時に正しく読めないか(第2章問題20)。
- 欠落の確認: 音の高さ・図表・記号が選択肢から抜けていないか(第5章問題26)。

## 4. 事実確認(未了のものは「未検証」と明記する)
- 法令の条番号は必ず一次情報で確認する。v2では日本語教育推進法の条番号が複数誤っていた(基本理念は第3条、国の責務は第4条、地方は第5条)。
- 統計の年次、制度の名称(JF日本語教育スタンダードが正式名称)。

## 5. 修正の作法
- docxのXMLを直接直す場合は、段落の書式(太字・色ラン)を保つ。正誤タグは色付きの別ランなので、入れ替えるときは色も入れ替える。
- 修正後は必ず`quiz_audit.py`を再実行し、指摘が増えていないことを確認する。
- 変更は`修正一覧_*.md`に残す。復元・書き直した文面は「要確認」と書く。
- この環境ではLibreOfficeがdocxを開けなかったため、表示確認は人がKindle Previewerで行う。
