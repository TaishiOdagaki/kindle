# 香月涼 無料定期便フォーマット

池辰彦氏の連載(目次・vol番号・定型の締めで習慣読者を作る型)を参考に、香月涼のトーン(静かで率直、説教臭くない、少しだけ鋭い)に合わせて設計したテンプレート。

これは**無料**で高頻度に出す「定期便」で、単発の有料エッセイ(001記事のような告白＋ノウハウ型)とは別物。
定期便で習慣読者を積み上げ、有料エッセイで収益化する二層構造にする。

---

## 誌名・シリーズ名

**「静かな作戦会議」** （香月涼、隔週〜週刊）

*(候補: 「挽回ノート」「評価と自分を分けるノート」なども可。決めきる前に数本試して反応を見てもよい)*

## vol番号のルール

- vol.001 から開始。週1〜2回のペースなら半年でvol.026〜050あたりに到達し、「継続している」こと自体が信頼になる
- 号数は本文冒頭、タイトルの下に小さく表示（池辰彦氏と同じ位置）

## 定型フォーマット

```
[タイトル：対比構造 or 定説を疑う疑問形]

香月 涼
YYYY年M月D日 HH:MM　フォローする
vol.XXX

――――――――――――――――

[書き出し：1〜3文の短いフック]
時事ニュース、読者から届いた話、あるいは香月涼自身の観察のいずれかから入る。
自分の告白から入る回もあってよいが、定期便では「今、世の中で起きていること」を
入口にする回を基本とする（001のような単発エッセイとの違いを出すため）。

目次
・（本文の柱1）
・（本文の柱2）
・（本文の柱3）

――――――――――――――――

## （柱1の見出し）
時事ニュースや調査データを1〜2件紹介する。出典は実在の報道・統計を明記する。

## （柱2の見出し）
「世間の定説」を一度置いて、それを疑う視点を出す。
ここで三本柱（自己肯定感の回復／挽回転職／静かなリベンジ）のいずれかに接続する。

## （柱3の見出し）
香月涼自身の経験や、読者から届いた声を短く挟む。
教訓を押し付けず、「私はこう考えている」という一人称の意見として書く。

――――――――――――――――

[結びの一文：静かに、断定せず、少し鋭く]

（定型の締め）
今日はここまで。
評価は、あなたの価値を決めない。

（任意：読者の声の紹介があれば挿入）
```

## 香月涼版の「定型の締め」候補

池辰彦氏の「本日も最後まで読んでいただき、誠にありがとうございました！😊」は明るく親しみやすいトーン。
香月涼はこれと逆の温度感（静かで、断定しない、少しの余韻を残す）にする。

以下から1つを選び、**毎回同じ文言で固定**することで「儀式」として読者に認知させる。

1. **今日はここまで。評価は、あなたの価値を決めない。**
2. **今日はここまで。悔しさは、消さなくていい。**
3. **今日も、誰かの評価ではなく、自分の基準で一日を終えられますように。**

→ 候補1を推奨。三本柱の中心思想（「あの人たちの評価がなくても、自分の人生を選べるようになることが本当の挽回」）と直結していて、シリーズを通じてブランドの一貫性を作れる。

---

## 「フォローする」導線・読者との交流

- 池辰彦氏同様、冒頭に「フォローする」の導線テキストを置く
- 読者からの反応（コメント、紹介記事、似た体験談）があれば、定型の締めの後に短く紹介する回を作る
  → 読者が「自分の声が届く」と感じ、継続読者化につながる

---

## 定期便と有料エッセイの役割分担

| | 定期便（無料） | 単発エッセイ（有料） |
|---|---|---|
| 頻度 | 週1〜2回 | 月1〜2回 |
| 入口 | 時事ニュース・データ・読者の声 | 香月涼自身の具体的な体験談 |
| 目的 | 習慣読者の獲得、信頼の蓄積 | 収益化 |
| 三本柱との関係 | 3本柱を横断的に、軽く触れる | 1本柱を深く掘り下げる |
| 締め | 定型句で儀式化 | 有料の壁の手前で興味を引き切る |

反応が良かった定期便のテーマ（例：「屈辱の直後に転職してはいけない理由」に読者の反応が集まった等）を、
そのまま次の有料エッセイの深掘りテーマに昇格させる、という連携を想定する。
