# 年度に依存しない恒常版の編集方針
決定日: 2026-10-28
対象: 登録日本語教員試験 パーフェクト問題集（2027年度版として準備していた改訂稿）

## 編集決定
- 読者向けタイトル・巻頭・章見出し・解説・巻末・商品説明から「2027年度向け」「今年度」「来年度」「最新」といった短期有効表現を、内容に適合する年度非依存の表現に改める。
- 制度の条文・施行日・過去の試験の実測値・問題の条件として必要な年号は削らない。史実と施行予定を混同しない。
- 問題文に付属する「2026年10月20日確認」等は、削除するだけでは問題の解釈が変わり得る。一次資料の名称・対象範囲・基準日を保持するか、施行後も真になる命題へ根拠付きで再構成する。
- 将来の試験形式・制度改正を保証しない。「最新の制度」と称する表現は避け、公式情報で確認する旨を必要に応じ明示する。
- 年度依存17段落の既存チェックリストは Library `2027_年度依存記述_監査対象17件.csv`。第3次編集稿に対する検出のため、後続の第4次稿や改訂レイアウト稿でも再検査する。
- 育成就労制度の施行日 2027-04-01 は制度史上意味を持つため、根拠のない年号削除をしない。

## 巻頭文・改訂候補
「本書は登録日本語教員試験に関係する学習事項を、四肢択一の500問と各選択肢の解説で確認する演習問題集です。巻末の75問は基礎60問・応用読解15問の短縮演習であり、公式試験の問題数・試験時間・聴解を再現する完全な模擬試験ではありません。試験の実施要項や受験資格等は受験時点の文部科学省の公式情報をご確認ください。」

## 変更適用と検査条件
1. 最新原稿の確定前に、古い第3次稿へ自動置換を行わない。
2. 全17段落と後続原稿の追加箇所を、分類（年度宣伝／資料基準日／史実／未来予定／制度依存）して原文・改訂案・根拠・採否を台帳化。
3. 設問と選択肢を改める場合は正答・4肢解説・資料根拠をセットで再監査する。
4. 本文反映後、500問と解説の構造回帰・実際のDOCXとEPUB表示検査を行う。
5. 出版はユーザー承認まで行わない。
